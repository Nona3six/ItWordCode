Draft game scoring added:
Starting score is 6, which allows for the 6 correct guesses required to complete the game
1 point deducted for every guess made (only incorrect guesses negatively impact score)
Scrabble scoring system applied to the word entered for each correct guess and added to running total
1 point deducted for every full minute it takes to complete the game (2min59sec would see 2 points deducted)
**scoring needs testing and refining
